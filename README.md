# Smart Vehicle Parking Management System

A full-stack Smart Vehicle Parking Management System project.

## Project Structure

- `backend/`: Java Spring Boot, Maven, REST API, MySQL database configuration.
- `frontend/`: Single-page client app using semantic HTML5, custom CSS styling, and JavaScript logic.

## Getting Started

### Prerequisites
- Java 17 or higher
- Maven 3.6+
- MySQL Server 8.0+

### Recommended Setup
Set the root `smart-parking-system` directory as your active editor workspace.
